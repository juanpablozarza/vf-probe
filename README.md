# vf-probe

Probe [verifiers](https://github.com/PrimeIntellect-ai/verifiers) environments
to see whether their graders reward the wrong thing.

Status: early / WIP. The CLI is a stub. The design is in [docs/PLAN.md](docs/PLAN.md).

## Install

```bash
uv sync
```

## Usage

```bash
vf-probe <env-id>
vf-probe <env-id> --out reports/run
```

The command currently prints `not implemented yet` and exits with a non-zero status.
